# Mock GPS

Приложение для подмены геолокации на Android 8.0 и новее.

**[Скачать APK](https://github.com/strikec71/GPS-Mocker-by-phx/releases/latest/download/Mock-GPS.apk)** · [Все версии](https://github.com/strikec71/GPS-Mocker-by-phx/releases)

1. Скачайте и откройте APK. Если Android запросит разрешение на установку из этого источника, разрешите её.
2. В настройках разработчика откройте пункт выбора приложения для фиктивных местоположений и выберите **Mock GPS**.
3. Откройте приложение и разрешите доступ к точной геолокации. Выберите точку на карте или введите координаты вручную.

Карта использует данные [OpenStreetMap](https://www.openstreetmap.org/copyright).
